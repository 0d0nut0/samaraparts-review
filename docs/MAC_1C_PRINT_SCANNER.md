# Zebra ZD420 и сканер на втором Mac

Проверено по переписке: Zebra уже добавлена в CUPS, PDF печатается; этикетки формируются в 1С, но кнопки «Печать» и «Предварительный просмотр» не открывают системное окно. Оборудование находится на другом Mac, удалённо его работоспособность здесь не проверялась.

## Сначала печать 1С

1. Сохраните **одну** этикетку из 1С в PDF и откройте в «Просмотре». Если она печатается на Zebra, очередь и принтер работают. Переустанавливать CUPS с этого шага не нужно.
2. В 1С сформируйте обычный счёт и попробуйте предпросмотр. Если не открывается даже он, сбой происходит до отправки задания принтеру: в веб-клиенте, генерации PDF или браузере. Это направление диагностики, а не установленная точная причина.
3. Для `https://v12.arenda-it.com` разрешите всплывающие окна и переадресации в настройках сайта Chrome. Проверьте, не блокируется ли новая вкладка/PDF значком в адресной строке. Настройки других сайтов менять не требуется.
4. Откройте Chrome → Настройки → Конфиденциальность и безопасность → Настройки сайтов → Дополнительные настройки контента → PDF. Для проверки выберите открытие PDF в Chrome; если выбран режим скачивания, ищите документ в загрузках.
5. Проверьте одну и ту же печатную форму в актуальных Chrome и Safari. Если ошибка повторяется, запишите версию платформы 1С и сообщение консоли браузера после нажатия кнопки. В Chrome консоль: ⌘⌥J. Секреты и пароли из журнала не пересылайте.
6. Попросите облачного провайдера проверить печать/генерацию PDF на текущей версии платформы и доступ через тонкий клиент macOS. Версия клиента должна соответствовать платформе сервера, сборка — архитектуре Mac. Саму базу переносить не требуется, если провайдер поддерживает подключение.

Zebra Browser Print — отдельный механизм для приложений, которые его используют. Его установка сама по себе не добавляет такую интеграцию в 1С. Компоненты 1С устанавливайте из интерфейса 1С/официального источника, если она прямо просит подходящую компоненту для macOS.

## Когда откроется окно печати

Для уже настроенной этикетки 45 × 25 мм: выбрать Zebra ZD420, этот же размер бумаги, масштаб 100%, без «вписать в A4», колонтитулы выключить. Сначала одна этикетка. Если текст или штрихкод обрезаны, сверить ориентацию, фактический размер страницы PDF и размер материала в CUPS.

CUPS на macOS поддерживается как способ подключения принтеров Zebra. Поскольку Ваш PDF уже печатается, первым проверяется вызов печати из 1С.

## Сканер: простое подключение

1. Подключить сканер по USB или Bluetooth в режиме **HID / Keyboard (эмуляция клавиатуры)**. Настройка режима выполняется по инструкции именно Вашей модели сканера. Обычно отдельный драйвер Mac для такого ввода не нужен.
2. Открыть «Заметки», поставить курсор и считать один штрихкод. Должны появиться ровно 13 цифр EAN-13, без пробелов и префиксов, затем Enter. Нужны передача контрольной цифры и суффикс Enter/CR. Для кодов с буквами дополнительно проверить раскладку.
3. В 1С открыть команду **поиска по штрихкоду** (значок штрихкода в номенклатуре/подборе товара), поставить курсор в её поле и отсканировать. Общий текстовый поиск по названию не всегда ищет в регистре штрихкодов.
4. Если цифры в «Заметках» правильные, а товара в 1С нет, открыть карточку товара → «Штрихкоды». Код должен быть зарегистрирован там, а не только написан в описании или артикуле. Ранее проверенные 676 позиций и четыре дополнения из заказа № 280 зарегистрированы; для остальных товаров это проверяется отдельно.
5. Для автоматического приёма сканирования без курсора: НСИ и администрирование → РМК и оборудование → Подключаемое оборудование → Сканеры штрихкода. Выбрать поддерживаемый драйвер «1С:Сканер штрихкода (NativeApi)», проверить совместимость компоненты с macOS/Apple Silicon и выполнить тест устройства. Для веб-клиента может потребоваться подходящая компонента. Если она не поддерживается на конкретном Mac, остаётся рабочий ввод HID в выбранное поле.

Код товара определяет номенклатуру, а не уникальную физическую штуку и не партию FIFO. Одинаковые товары могут иметь один штрихкод; себестоимость партий рассчитывает учёт в 1С.
